# تقرير التنفيذ — نبتة

التاريخ: ٢٣ أكتوبر ٢٠٢٦. المستودع: `/workspace/lingo`.

تم بناء أساس MVP وظيفي يعمل مع PostgreSQL؛ لم يُنفذ المنتج الكامل بكل مراحله، ولم يُنشر على استضافة إنتاجية.

## ما تم تنفيذه

- مشروع Next.js / TypeScript / Tailwind بواجهة عربية RTL ومتجاوبة، وهوية وأصول SVG أصلية وخط عربي محلي.
- حساب ولي أمر، كلمات مرور مشفرة، جلسات HttpOnly وصلاحيات منفصلة لوضع الطفل، وإنشاء وربط ملفات الأطفال.
- تقييم أولي من ٨ أسئلة، دروس من ٦ أنشطة، حفظ الإجابات، تغذية راجعة عربية وتفسير ومثال، تحديث الإتقان والثقة والأخطاء، واختيار النشاط التالي على الخادم.
- مخطط مهارات حي من قاعدة البيانات، مراجعات متباعدة، أوزان اختيار قابلة للتغيير، تنويع داخل الجلسات القصيرة، وتدخل شرح ثم مثال ثم نشاط أسهل عند تكرار الخطأ.
- تسجيل الوقت النشط منفصلًا عن مدة الجلسة، استبعاد الخمول، تسجيل المغادرة، ومؤشرات أداء سلوكية أولية دون تشخيص نفسي.
- تقارير الطالب وولي الأمر ومقارنة أسبوعية بالطالب نفسه، بيانات المهارات، توصيات أولية، وإفادة اختيارية حول صعوبات الدراسة تُسجل بوصفها إفادة ذاتية.
- XP وسلاسل استمرار وشارات وشخصيات مكتسبة وأفضل أسبوع شخصي وإعدادات الهدف اليومي.
- طبقة سياسة محتوى وتصنيف ومراجعة، ومسار عزل للمحتوى المولد، وتجريد AIProvider مع تعطيل المعلم الآلي في هذه النسخة.

الأنواع العاملة: الاختيار المتعدد، إكمال كلمة، ترتيب كلمات، الاختيار البصري، وفهم مقروء قصير. بقية أنواع الأسئلة لها تمثيل معماري، وليست تجارب تعليمية عاملة بعد.

## المعمارية وقاعدة البيانات

Modular Monolith: واجهة → API يتحقق من المدخلات والصلاحيات → خدمة معاملات → محركات مستقلة قابلة للاختبار → Prisma JS / PostgreSQL.

٣٨ نموذجًا، وترحيلان SQL، وعلاقات ومفاتيح أجنبية وفهارس وقيود تحقق. تشمل المهارات والمتطلبات، المنهج والأسئلة، الإجابات والأخطاء، الإتقان والثقة، المراجعات، الجلسات والسلوك، التدخلات ونتائجها، التحفيز، الأصول وسياسة المراجعة. الـseed يضيف ٢٢ مهارة و٤٠ سؤالًا و٦ دروس، دون حسابات جاهزة للأطفال.

تستخدم العمليات التعليمية معاملات وقفلًا مناسبًا، وتمنع مضاعفة تسجيل الإجابة والمكافأة. لا تُرسل الإجابة الصحيحة قبل التسليم، ولا يقرر المتصفح الإتقان أو المكافأة. توجد أسس جداول للأهداف الأسبوعية والأنماط والمجاميع؛ ليست كل هذه الأسس عمليات مجدولة أو ميزات منتج مفعلة.

تختبر رحلة المتصفح التسجيل والملف والتقييم وإعادة التحميل والدرس والتقرير وإفادة ولي الأمر، ومنع حساب آخر من الوصول، ورفض مصدر طلب خارجي. تختبر أيضًا تنقل الهاتف والتركيز داخل النوافذ وحالة تعطل الخادم. اختبارات التكامل تتحقق من الحفظ والإتقان والأخطاء والمراجعات، والتزامن وعدم مضاعفة المكافآت، والوقت النشط، وقيود قاعدة البيانات، ومسار المساعدة وتسجيل نتائجه.

ظهرت أثناء التطوير أخطاء فعلية وأُصلحت: تصادم ملفات بناء التطوير والإنتاج، مقارنة Origin خلف خادم التطوير، ذاكرة Prisma القديمة بعد إعادة توليد العميل، وحالة انتقال إنهاء الجلسة. تحذير deprecation من pg/Prisma عند تنفيذ بعض المعاملات ما زال موجودًا؛ لم يؤد إلى فشل اختبارات أو فقد بيانات. أخطاء قيود PostgreSQL المطبوعة في اختبارات المدخلات الخاطئة متوقعة ومقصودة.

## قيود البيئة والمنتج

- Docker غير متاح للحساب. شُغلت قاعدة PostgreSQL محلية فعلية بواسطة الحزمة الاختيارية embedded-postgres.
- الشبكة تحجب ملفات Prisma التنفيذية. جرى توليد العميل بواسطة API مثبتة الإصدار، وتنفيذ SQL مباشرةً بأداة ترحيل تتحقق من checksums وتستخدم transactions. أمر Prisma CLI المعتاد للترحيل لم يُتحقق منه هنا، وهو متاح في بيئة تسمح بتنزيل الملف التنفيذي.
- لا يوجد نشر إنتاجي أو رابط موقع منشور. التشغيل المستهدف Next.js مع PostgreSQL، لا نسخة محاكاة مبنية لتناسب استضافة مختلفة.
- المحتوى الأولي من تأليف آلي أصلي وفحوص أولية موثقة؛ ليس حاصلًا على اعتماد تربوي أو مراجعة بشرية مستقلة. يحتاج إلى مراجعة مختص قبل الاستخدام الحقيقي.
- لا توجد محادثة AI أو نطق أو استماع فعلي أو تحليل كتابة حرة. إدارة المراجعة البشرية والمنهج الكامل والمهمات المستهدفة للإتقان وعالم المكافآت المتوسع أعمال لاحقة.
- لا توجد بعد استعادة كلمات المرور أو تحقق البريد أو إبطال جلسات فردية عبر الأجهزة أو نظام موافقة ولي الأمر الخاص بالسوق أو إجراءات حذف/تصدير واحتفاظ إنتاجية مكتملة.
- تقديرات الإتقان والأداء أولية وتحتاج إلى معايرة. التقييم القصير ليس اختبار CEFR معتمدًا. تحليل المدة المثلى له دالة وقاعدة أدلة، لكنه غير مفعل كتوصية طولية نهائية في اللوحة.
- التقارير تُحسب عند الطلب. لا توجد وظيفة مجدولة بعد لتجميع جداول weekly metrics/patterns. تنقل الشاشات الأساسي داخل واجهة واحدة؛ ليست جميعها روابط مستقلة قابلة للمشاركة.

## المرحلة الموصى بها

توسيع المحتوى بمراجعة تربوية وبسياسة التطبيق، وزيادة الأسئلة العلاجية والمراجعات، ثم تقوية الهوية واستعادة الحسابات وموافقات ولي الأمر والاحتفاظ بالبيانات، وتجهيز نشر حقيقي مع PostgreSQL مُدار. بعدها تُضاف أنشطة الاستماع والنطق والمعلم الآلي عبر بوابة المراجعة القائمة.

## التشغيل المحلي الدقيق

من جذر الشيفرة، باستخدام Node 22.12+:

```bash
npm ci
cp .env.example .env
```

استبدل AUTH_SECRET في `.env` بقيمة عشوائية لا تقل عن ٣٢ حرفًا. أبقِ DATABASE_URL المحلي كما هو إذا ستستخدم القاعدة الاختيارية.

```bash
npm run db:generate
npm run db:local
```

اترك قاعدة البيانات تعمل، وافتح طرفية ثانية في جذر المشروع:

```bash
npm run db:apply
npm run db:seed
npm run dev
```

افتح `http://localhost:3000`. لا توجد بيانات دخول افتراضية؛ أنشئ حساب ولي أمر من الواجهة. بدلًا من `db:local` يمكنك استخدام قاعدة PostgreSQL موجودة وتعديل DATABASE_URL، أو `docker compose up -d db` عندما يتوفر Docker.

للتحقق والبناء:

```bash
npm run typecheck
npm run lint
npm test
npm run test:integration
npm run test:e2e
npm run build
npm start
```

اختبارات المتصفح تحتاج Chromium؛ يمكن تحديد مساره بواسطة CHROMIUM_PATH. أعد تشغيل خادم التطوير بعد تغيير المخطط وإعادة توليد عميل Prisma. تفاصيل الإعداد والنشر والقرارات في README وملفات docs الأخرى.

فحص التشغيل والإصلاحات اللاحقة موثقة في `docs/runtime-audit.md`. لم يتغير تصميم الشاشات أو متطلبات المنتج.
